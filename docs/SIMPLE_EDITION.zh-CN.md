# 0.5.13 简易版与开发版

日常使用 `overwatch-helper-simple.exe`；需要高级设置、演练、页面校准、导入和诊断时使用 `overwatch-helper-dev.exe`。两者共用识别与恢复内核，同时只能运行一个助手。请先关闭旧助手，再打开新版。

## 简易版

界面只有挂机模式、开始挂机、停止/F8、重启游戏、前台使用和失败记录。页面规则与 OCR 脚本嵌入 EXE，单独复制 EXE 也可运行，无需在旁边放 profiles 或 ocr-worker.ps1。运行时自动把内嵌 OCR 脚本展开到自己的数据目录，并复用 Windows 本地 OCR；不需要手动校准。

1. 选择“战令房间”或“自由死斗”，再选择前台或后台（实验）。
2. 点“开始挂机”。简易版执行真实操作，自动识别、进房和恢复；在当前对局中启动时仍会确认局内画面。
3. 需要使用电脑时，点“前台使用”。**按钮无需等待 OCR 识别，可直接点击。** 如果助手未运行，会按当前模式启动；随后核验游戏窗口、PID、创建时间与权限，最小化游戏并发送定向后台消息。请在对应房间/对局内使用这个按钮；没有游戏窗口时会说明原因并记录，不会向其他前台程序发按键。
4. 再点该按钮或切回游戏，恢复识别；停止/F8 释放自有按键。重启游戏沿用游戏退出确认、同安装目录加载器/客户端残留核验和战网重新启动流程。

选择后台模式时，在连续确认局内后自动进入一次后台模式；手动切回游戏后恢复检测，再次后台挂机可点“前台使用”。后台模式暂停 OCR、导航、掉线恢复及死斗结算重排；需要处理结算或掉线时切回游戏。游戏需窗口化，最小化后的消息是否被当前游戏接受仍需实测，状态会显示“效果待验证”。

简易版内置开启挂机按键、本地识别、自动恢复与每秒 Shift 点按；前台有人操作时保留待机保护。自定义房间目标初次沿用已有开发版设置，默认“最稳轮换版”。需要换目标或其他高级参数时使用开发版。

## 路径与记录

简易版数据位于 `%LOCALAPPDATA%\OverwatchHelperSimple`，开发版继续使用 `%LOCALAPPDATA%\OverwatchHelper`。初次读取开发版已有启动器、游戏组件路径与房间目标；后续保存自己的模式和设置，路径失效时重新自动发现或读取开发版修正值，不覆盖开发版配置。

失败自动保存到 `failures.log`，包含本机时间、状态、PID 和具体提示，界面显示最近 200 条、最新在上。“打开失败日志”可查看文件；重开助手后仍保留。超过 1 MiB 的日志改名归档，不批量删除。完整状态变化和未识别画面仍保存在自己的 agent.log、adaptive、unmatched 目录。

记录输入拒绝、OCR/截图不可用、安装路径问题、进程异常、登录/连接错误和自动恢复原因。相同连续状态不重复记录，正常等待和手动重启不作为失败。网络错误的具体来源仍需结合原生日志确认。

## 开发版与验证

现有 0.5.12 EXE 已原样保存为开发快照。0.5.13 开发版保留完整界面，并同样修复前台按钮锁灰、内嵌识别资源和自动失败记录。兼容名称 overwatch-helper.exe 供原有演示/诊断脚本使用。

16 项 CTest 通过，覆盖实际简易版控件、模式保存、独立设置、失败记录重载、缩放/DPI、无 OCR 证据时点击前台使用、定向按键和停止释放。额外在只有 EXE、没有外置脚本的目录验证中文 OCR、坐标和自动学习缓存。测试未对真实游戏发送输入、关闭或重启。
