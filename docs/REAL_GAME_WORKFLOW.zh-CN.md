## 自定义房间的历史流程

战网“进入游戏” → 可能出现 NeacProtect 管理员授权 → 游戏登录/加载 → 主界面“开始” → “更多模式” → “自定游戏” → 选择目标模式卡片 → “自动加入” → 房间大厅或“正在进入比赛” → 可能先观战 → 回合结束与结算 → 自动重开 → 本人进入对局 → 每秒点按左 Shift。

房间会自动轮换对局，不需要每轮重新点击加入。用户报告中途加入时需要等到下一回合才开始获得经验；静态截图不能验证经验是否发放。当前流程展示了模式自动将玩家带入托比昂对局，未展示手动选英雄步骤，暂不凭空增加选英雄操作。

浏览页当前有三个托比昂战令模式卡片；截图里实际选中的是“托比昂战令 最稳轮换版”。这是模式列表中的卡片，“自动加入”随后分配房间，不应理解为固定房间实例或永久固定的左下坐标。后续应按模式名称/明确选择验证目标；其他模式是否允许作为备用需要单独确定。

## 自定义房间会话与当前输入行为

0.2.0 已实现房间会话：连续两帧识别“到达目标房间”后，在同一游戏进程内保持点按资格。普通未识别帧、观战、加载或结算无需分别分类。已识别的菜单/导航、掉线页、互斥模板歧义、游戏实例变化以及用户停止清除会话。已录为导航或错误的页面优先于“继续点按”，所以不要把正常结算录成错误页。

房间参考优先试 E 齿轮图标。模板仍为 32×16 灰度，Ready 样本允许很小的位置容差；同类 Ready 或 Restart 模板作为外观变体，不会互相造成歧义。E 图标也会出现在观战、其他托比昂房间中，只能确认所录 HUD 特征，不能单独认证目标模式。首次由用户确认目标房间；恢复导航需要保留模式卡片身份校准。

默认点按与用户已验证的 PowerShell 脚本一致：`keybd_event(VK_LSHIFT, 0, 0, 0)` → 等待 20 ms → 左 Shift 抬起，约每秒一次。助手用开始/F8 控制，不额外依赖 CapsLock。可改成持续按住，但持续按住只在前台生效。

旧版“切到后台仍全局点按”已经移除。当前仅在目标窗口前台发送；手动按住 Shift 时跳过本次脉冲，避免主动松开用户正在按的键。F8/停止通过运行代次与输入锁中止后续发送并释放自有按键，失焦和安全桌面也会释放。

失焦、遮挡、最小化和锁屏时不使用新的游戏图像证据，也不向别的应用发送挂机输入。返回后重新检查页面。普通未知帧只可保留已经确认的自定义房间会话，**不能证明本次加入成功**；死斗未知帧会撤销随机输入资格。

## 掉线恢复

录制蓝色错误页中的稳定错误文字，不把“蓝色”本身当作断线依据。连续匹配 90 秒后关闭已核验的游戏进程，等待退出完成，再核对同目录残留 `NeacLoader.exe` 与 `OWNeacClient.exe`，最后从战网“进入游戏”重新启动、按原录制路径进房。游戏内“登录”按钮不在此恢复路径中。

残留清理要求配置其完整 EXE 路径，并核验实际运行路径、PID 和创建时间；每次结束前再次确认没有任何 `Overwatch.exe`。不按 neac 通配符清理、不处理服务/驱动，也不尝试绕过进程保护。缺少路径时要求配置；核验/结束拒绝记录具体原因并重试最多 15 秒，到期停止本次启动，不结束无法核验的进程。先结束加载器以防重新拉起客户端，再核对两者都已消失。启动等待期间不清理刚启动的客户端；启动 120 秒仍无游戏时，在恢复预算内只允许重新清理后再启动一次。

冷启动/主动重启缺失先等 3 秒，运行中游戏自行消失先等 30 秒；等待结束后才检查残留。恢复每小时最多 3 次，保留冷却。输入桌面不可访问或与当前线程桌面不同时释放输入并暂停启动超时。当前掉线连续证据采用 5 分钟采样间隔容忍，识别到不同页面清零，不因短暂待机而反复重来。

用户已确认每次重启都有 NeacProtect 管理员授权。因此仍需要用户在显示器上处理授权，当前版本不能完成包含此提示的全程无人值守恢复。程序不更改 UAC 策略或安全组件。

## 统计与验证边界

有效对局计数暂未实现；观战识别不再作为发送 Shift 的前置条件。后续可低频补充本人 HUD、观战标记和结算特征，仅用于计数，并以一次完整回合的状态过渡去重。新增少量小区域模板不需要引入模型；真实额外耗时与误判率仍需测量。不能用会话运行时长直接换算战令经验。

截图离线抽样发现：以 23:39:16 的 E 图标为参考，约 2 像素容差后，其他三张技能变化截图的近似分数为 0.964、0.926、0.899；阈值仍是 0.90，最后一张并不通过。这正是保留房间会话和允许额外样本的原因，不宣称一张模板覆盖所有情况。该抽样假设顶端 28 像素为标题栏，手动截图裁切存在差异，不能替代真实客户区回放。

本机新增测试覆盖会话保留/清除、同类模板、位置容差、连续错误时间中断、配置往返、停止与旧代次点按拒绝、残留路径白名单。没有结束本机实际游戏或 Neac 进程，也未向它们发送测试输入；真实重启与授权流程尚需实测。

API 依据：[keybd_event](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-keybd_event) 无成功返回值，界面表示“请求点按”而非游戏已接受；[OpenInputDesktop](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-openinputdesktop) 用于检查输入桌面可访问性；[TerminateProcess](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-terminateprocess) 为异步结束，需要等待句柄确认退出。
