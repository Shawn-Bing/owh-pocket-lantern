## Windows 首轮验收

建议先按照 `QUICKSTART.zh-CN.md` 跑模拟窗口，再试真实游戏：

1. 默认演练模式下校准大厅、列表、目标房间和错误页，确认匹配到正确页面。
2. 模拟窗口中验证自动导航和 Shift 状态；F8、停止、退出均应停止发送并释放 Shift；关闭后台选项时失焦停止，开启时继续全局点按。
3. 模拟断线，确认延时恢复；F9 关闭模拟窗口，确认重新启动与导航。
4. 国服战网保持登录，录制实际启动按钮和固定房间路径。先演练，再启用动作。
5. 检查游戏真正接受点击、中文搜索、Enter 和 Shift；不同权限等级、渲染模式或界面布局可能需要调整。
6. 断网、游戏退出、登录页停滞后验证恢复边界；观察 `WAITING_FOCUS`、`NEEDS_USER` 和 `BACKOFF` 的原因。
7. 用任务管理器记录客户端与游戏各自的 CPU / 内存，再做至少一轮较长运行，以实际测量判断资源和稳定性。

不把“进程存在”当成“已进入房间”；远程 `ACTIVE` 只表示本轮游戏已匹配过用户录制的房间特征且处于房间会话，不证明当前参赛或获得经验。校准错误或特征不唯一仍可能误判。
