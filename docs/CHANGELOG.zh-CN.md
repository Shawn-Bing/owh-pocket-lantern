# 本次改动说明

## 2026-09-20 · 助手 0.3.0 / 记录器 0.1.1

本次提交汇总初始原型之后的本机开发：补齐掉线证据采集、截图兼容、房间会话与恢复流程，并提供可直接测试的重启入口。看板包含此前新增的后台点按和等待授权状态支持。

### 游戏重启与重新进房

- 新增“重启游戏”按钮，与自动恢复共用演练、恢复预算和退出流程；关闭前检查启动配置及客户端路径。
- 游戏退出完成后，核对绝对路径、PID 与创建时间，再清理同一安装目录的残留 `OWNeacClient.exe`；无法核验或权限不足时暂停。
- 战网未运行时打开配置的启动器；进程存在但没有可见主窗口时尝试唤起。窗口枚举优先选择主窗口，避免选中微小辅助窗口。
- 内置国服登录超时、主菜单、更多模式、自定义浏览页、最稳轮换版及 E 技能参考。明确的登录错误连续出现 90 秒才触发恢复，普通蓝色加载画面不触发。
- 浏览页同时核对标题与目标模式，先选择目标卡片，再确认加入状态；选择证据过期、切换页面、停止或进程变化后失效。
- 战网联网后弹出并持续遮挡游戏 5 秒时，尝试一次切回游戏；同一遮挡期间不反复切换。

### 房间会话与操作控制

- 默认约每秒点按左 Shift，按下 20 ms；可选择后台全局点按或前台持续按住，也可关闭助手输入、继续使用原 PowerShell 脚本。
- 连续确认房间参考后保留会话，允许观战、加载与结算时 HUD 暂时消失；识别到导航、错误、歧义或进程更换时清除会话。
- F8、停止和退出释放助手输入；校准可取消。运行代次阻止停止前的旧检测结果继续发送动作，失败输入也计入重试次数。
- 安全桌面暂停输入和启动超时；NeacProtect 授权仍需人工处理。

### 整夜记录器与截图修复

- 新增独立只读记录器，采集游戏截图、相关进程与窗口、网络参考探测、网卡与连接表、输入状态采样、原生日志及 Windows 事件。
- 支持事件附近加密截图、手动标记、停止并保存、无界面有界测试，以及时长、容量和剩余空间限制；保留旧记录。
- 修复 NVIDIA 被动悬浮层导致的误判，忽略系统隐藏及完全透明窗口；普通遮挡仍拒绝截图。
- 截图失败显示具体原因和遮挡程序，清空旧帧，并在复制前后核对窗口几何。

### 构建、诊断与说明

- 新增 Windows 一键构建、只读运行诊断、记录器启停及独立打包脚本；发布包使用文件清单和 SHA-256 校验。
- 新增国服模板生成及历史截图回放工具，补充核心、平台、记录器、识别和看板状态测试。
- 整理实际游戏流程、试用步骤、架构、验证记录与昨晚故障分析。原始录制、截图、个人配置、构建目录、EXE 和 ZIP 不纳入本次 Git 提交。

真实游戏关闭、残留清理、战网启动及授权后自动进房尚需完整实机测试。预设依赖已提供的布局与模式位置，不能保证其他布局；房间会话不等于有效对局或已获得经验。还原分辨率的图片来自缩略图，不替代独立实机分辨率测试。

昨晚记录支持短暂外网中断，也有明确不活跃移出提示；后半夜存在战网遮挡导致的画面盲区。桌面 `ow.exe` 仅静态核对，解包内容与旧逆向产物一致，未执行或修改原文件。
